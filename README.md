# http-server-from-scratch

A web server built from scratch using raw sockets, to learn how HTTP really works.

## Why I'm building this

Most web frameworks hide what happens between a browser asking for a page and the server replying. I want to understand that layer by building it myself, with no framework doing the work for me.

## What it will do

- Listen for connections from a browser
- Read and understand an HTTP request
- Send back a valid HTTP response (status code, headers, page)
- Handle more than one connection at a time
